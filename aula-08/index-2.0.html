Demo Lazy Loading 2.0

Demonstração controlada para inspeção no Network

Como Demonstrar

Abra o DevTools no filtro Img, recarregue a página e role até os cards. As imagens só são requisitadas quando entram na área visível.

Aqui o fetch busca apenas os metadados dos repositórios. O carregamento da imagem acontece depois, sob demanda, via IntersectionObserver.
